# Obsidian Graph View

Obsidian'da `Graph View` açın, ardından `Settings` → `Groups` → `New group` yolunu izleyin.
Her grup için aşağıdaki arama sorgularından birini kullanın:

| Group              | Search query               | Suggested color  |
| ------------------ | -------------------------- | ---------------- |
| Core / Product     | `tag:#memory/core`         | bronze           |
| Architecture / API | `tag:#memory/architecture` | blue             |
| Test / Quality     | `tag:#memory/quality`      | green            |
| AI / Report        | `tag:#memory/ai`           | purple           |
| Decisions          | `tag:#memory/decision`     | orange           |
| History / Issues   | `tag:#memory/history`      | muted red / gray |

Renkleri Obsidian arayüzünden seçin; belirli HEX değerleri zorunlu değildir.
